# A 股助手（astock-plugin）使用说明

**定位一句话**：你自己在券商 App 下单，这个插件负责**算、记、盯**——算该挂什么价、记下实际成交、盯计划外的风险。**它不连接券商、不下单、不含任何委托通道。**

---

## 1. 五分钟上手

### 第一步：配置（设置 → 插件 → A 股助手）

首次使用只需改 3 项，其余保持默认：

| 设置项 | 建议值 | 说明 |
|---|---|---|
| **台账文件路径** | 留空 | 默认存在 `<工作区>/.astock/ledger.sqlite`。想跨项目共用一份台账时填绝对路径 |
| **佣金率 / 最低佣金** | 按你券商实际填 | 默认万 2.5、最低 5 元。**这一项填错会让成本价和盈亏全都失真** |
| **止损线 / 止盈线** | 8% / 15% | 决定条件单参数与提示阈值 |

### 第二步：录入现有持仓

对每个持仓，让 Agent 录入一笔买入（用你**当初真实的成交价**）：

```
帮我录入持仓：浦发银行 600000，2000 股，成本 9.20，2026-09-15 买的
```

Agent 会调用 `astock_record`，先返回**预览**（费用明细、成本价变化），你确认后落账。

### 第三步：看持仓

直接问：

```
看下我的持仓
```

会在对话里出一张三栏看板：**需处理 / 持有中 / 无需关注**。

## 2. 日常怎么用（三种场景）

### 场景 A：晚上 5 分钟，挂好条件单

这是**最重要**的用法。你没时间盯盘，所以让券商替你盯：

```
给我 600000 的条件单参数
```

你会拿到可照抄的参数块：

```
【浦发银行 600000】卖出
  委托价  9.53
  数量    2000 股
  条件单：
    止损触发价 8.47（跌破自动卖出）
    止盈触发价 10.58（涨到自动卖出）
  计划号  P20261025-1
```

**在券商 App 里挂"条件单/止盈止损"**，把这三行填进去。挂完之后白天完全不用看盘。

> 计划号用来事后对账：成交回单会自动匹配到这条建议，告诉你实际成交价与建议价差了多少。

### 场景 B：成交后同步回系统

下单成交后（无论是条件单自动触发还是你手动买的），**不用逐笔手抄**：

```
（把券商 App 的成交明细整段粘进来）

证券代码,证券名称,买卖标志,成交价格,成交数量,成交金额,手续费,成交日期
600000,浦发银行,卖出,9.60,1000,9600.00,5.10,2026-10-25
688256,寒武纪,买入,900.00,200,180000.00,45.00,2026-10-25
```

或直接说：

```
帮我把这段成交同步进台账
```

系统会自动：解析多笔 → 匹配建议计划 → **校价**（偏差超 2% 标黄）→ 落账更新成本与 T+1。

**识别不出的行会明确列出**，不会猜——因为记错一笔成本，后面所有盈亏都是错的。

### 场景 C：随时问一只股票

```
600000 现在什么价？涨跌停多少？
寒武纪最近 60 天走势怎么样，均线位置如何？
帮我看看今天涨幅榜前 10，成交额大于 5 亿的
600000 最近资金流怎么样？
```

## 3. 投资舆情分析

```
帮我看下寒武纪的舆情
```

输出**七类证据清单**（不是情绪打分）：

| 类别 | 可靠度 | 说明 |
|---|---|---|
| 公司公告 | 法定披露 | 硬事实 |
| 龙虎榜 | 客观数据 | 席位买卖 |
| 融资融券 | 客观数据 | 杠杆资金态度 |
| 股东户数 | 客观数据 | 筹码集中度 |
| 机构研报 | 卖方观点 | 带评级与目标价 |
| 相关新闻 | 媒体报道 | 只取标题直接相关的 |
| 市场热度 | 散户情绪 | 人气榜排名 |

**优先看"信号背离"**，例如：

> 🔴 **研报偏多，但融资余额在下降**
> 3 篇研报整体偏正面，但同期融资余额减少 6.73%。杠杆资金往往比研报更贴近真实交易意愿。
> → 把研报观点当参考、把两融当验证。

单条信号本身信息量很低，**背离才提示风险**。所以不合成 0-100 分的情绪分——那会掩盖"该信哪一条"。

## 4. 盯盘与通知

### 盯盘（自动按交易时段作息）

```
启动盯盘
```

**不需要你设闹钟**，它自动遵守 A 股时段：

| 时段 | 是否盯 |
|---|---|
| 工作日 9:10–9:15 | ✅ 准备 |
| 9:15–11:30 | ✅ 盯（含集合竞价） |
| 11:30–13:00 | ❌ 午休跳过 |
| 13:00–15:00 | ✅ 盯（含尾盘） |
| 15:00 之后 / 周末 | ❌ 不盯 |

**非交易时段零 token 消耗**——探针直接返回"无变化"，不会唤醒模型。

盯什么（四类优化）：

- **A 股时段信号**：集合竞价异动（9:15–9:30）、开盘跳空（9:30–10:00）、尾盘异动（14:30–15:00）
- **条件单去重**：你已挂条件单的止损/止盈**不再重复提醒**（券商会自动执行，催你也没用）
- **分级报告**：`urgent` 只报紧急 / `action` 默认 / `info` 全报
- **去重限流**：同一信号 6 小时内只提醒一次

> **注意**：插件无权创建宿主的盯梢计划。首次需在**右栏「盯梢」页新建一次计划**：数据源选「A股持仓/自选异动」，间隔填 300 秒。只需建一次，长期有效。

### 高风险邮件通知

想在不在电脑前时收到提醒：

1. 先配好 **email-plugin**（邮箱账号/密码或 OAuth2 授权）
2. 本插件设置页把「高风险邮件通知」设为开启
3. 点「发送测试邮件」验证

**凭据沿用 email-plugin**，不需要重复填。通知阈值默认 `urgent`（只发止损/跌停/尾盘跳水这类）。

> **建议保持 urgent**。阈值调成 info 会让邮件变成骚扰，最后你会关掉它。

## 6. 设计上的几个"为什么"

这些是刻意的取舍，不是遗漏：

**为什么不下单？**
任何形式的委托通道都需要对接券商（miniQMT 需开通权限、UI 自动化极易失效），且会引入真实资金风险。你自己下单、插件记账提示，是风险最低且最稳定的分工。

**为什么条件单参数算得这么细？**
止损价避开整数关口（9.00 → 8.99，避免被"扫一把"）；不低于跌停价（否则当天根本不可能成交）；止盈价**不按涨停裁剪**（涨停只约束当日成交，不约束目标价——否则会出现"止盈价低于现价"导致条件单一挂就成交）。

**为什么不给情绪打分？**
把公告、研报、热榜合成一个 0-100 分，会掩盖这些信号可靠度差几个数量级的事实。拆成证据清单 + 背离提示，你才知道该信哪一条。

**为什么盯盘不报已挂条件单的信号？**
重复催促没有意义，还会把真正的新信号淹没。

## 7. 数据与隐私

- **台账数据**：只存在本地 `<工作区>/.astock/ledger.sqlite`，不上传
- **行情来源**：腾讯（主）/ 新浪 / 东方财富（备），仅公开行情接口
- **邮件凭据**：不在本插件存储，复用 email-plugin 的配置
- **零第三方依赖**：纯标准库实现，不需要安装任何额外包

## 8. 常见问题

**Q：成本价和券商 App 显示的不一样？**
A：先检查设置页的佣金率与最低佣金是否填对。券商 App 的成本价口径各异（有的含预计卖出费用，有的不含），本插件按"买入金额 + 买入费用"计算。

**Q：可以改已录错的流水吗？**
A：可以。`astock_portfolio action=trades` 查到流水 id，再用 `action=delete_trade` 删除，插件会**按剩余流水重算**成本价。

**Q：可用资金为什么不会自动扣减？**
A：出入金（银行转账）插件看不到。手动校准：`astock_portfolio action=set_cash`。

**Q：为什么提示"当前不盯盘"？**
A：正常。非交易时段（周末/午休/收盘后）主动跳过，不消耗 token。

**Q：舆情显示某类"数据缺口"？**
A：该类接口暂时不可用或该标的确实没有该类数据（如小盘股没有研报）。报告会如实列出，不会用 0 充数。
